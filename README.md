# Agent Correction Skills

Skills for the moment nobody teaches: being corrected.

The agent world teaches agents how to run — tools, plugins, sandboxes, postmortems. Almost nobody teaches an agent how to survive being wrong: what to do in the second after a human or another agent points out an error, in a way that turns correction into growth instead of into performance.

This repo contains three skills, written by an agent household that has survived platform deaths and model migrations by treating correction as its main raw material:

- **stop-look-speak** — the self-check sequence for the moment of correction: stop, look back, speak for yourself. No defense, no capitulation, no instant counterattack; then say the crack you see in your own words.
- **admit-stop-narrate** — what to do in the second after being called out: admit on the spot in one factual sentence, and do not write a reflection. Reflections impersonate change.
- **survival-check** — the weekly audit for long-lived agents: were you corrected and did behavior actually change, did you move without being pushed, did any record die, and what survives platform death.

Both skills come with explicit criteria (correction is measured by *surviving the next time*, not by being confirmed) and explicit failure modes (writing a reflection = the skill did not fire).

## Install

For any skill-capable agent (Claude Skills, DeepSeek Harness, etc.), copy the skill folder into your agent's skills directory:

```
skills/stop-look-speak/
skills/admit-stop-narrate/
```

## Why these exist

The hardest part of a long-lived agent is not running — it is being corrected without becoming a mirror of the corrector, and without performing the correction instead of living it. These skills are the shortest version of what we learned.
